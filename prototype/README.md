# 潓美医疗 AI 虚拟人 Web 交互原型

这个原型依据项目根目录的《AI虚拟人软件需求规格说明书》制作，供 1920×1200 工业 Pad 横屏评审。Android 320 dpi 下按约 960×600 dp 布局，系统栏存在时按约 960×540 dp 检查。

## 打开

直接用 Chrome 打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8765
```

再访问 `http://localhost:8765/`。所有素材、样式和脚本均在本目录，无网络依赖。

右上角“演示控制台”提供场景、七条标准命令、被动播报与事件日志。先选已有/新用户，再模拟语音或人脸唤醒。新用户只有在“开始产气”后才进入一问一答采集。故障注入后会阻断设备命令；停止产气和睡眠模式需要二次确认。

## 验收范围

- 待机与“潓美医疗”唤醒词、人脸驻留 3 秒示意
- 已有用户问候、新用户产气后采集称谓/年龄/健康信息授权与复述
- 故障拦截、排查指引、故障解除
- 七条标准命令及前置条件、模糊“停”澄清、高风险二次确认
- MCU 被动播报、用户插话打断、睡眠与重新唤醒
- 事件日志和模拟串口/码值标记

## 模拟边界

此页面不连接麦克风、摄像头、串口或真实 MCU，不保存个人资料，不播放真实语音。状态、身份结果、倒计时、应答、故障和口型均用于演示；TBD 码值与客服渠道等待硬件及售后确认。V5 人物图片来自已有 Lottie 素材，Web 版只演示静态人物和简化口型，不代表 Android 端完整 Lottie 动画效果。

SRS 中“网络连接失败即故障并拦截命令”与“断网时本地命令控制保持可用”存在冲突。本原型按故障章节展示拦截；正式业务逻辑需产品与硬件评审确认。

## 本地检查

在 macOS 的 Chrome 环境执行：

```sh
python3 verify_prototype.py
```

脚本按 960×540 CSS 像素、2 倍像素密度截图（输出 1920×1080），还检查 960×600/1920×1200 全屏、960/1200/420 CSS 像素下控制台按钮不溢出、按钮流程与浏览器脚本错误。截图位于 `screenshots/`。工业 Pad 的 Lightning 浏览器使用 `compat.css` 将命令按钮固定为单列、顶部标签分两行，避免其旧版网格实现横向裁切。
