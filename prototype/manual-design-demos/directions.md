# 手动界面方向探索

六个结构候选：

1. A「状态 + 直接操作」：左侧大状态，右侧四个高频操作，低频命令收在第二行。主角是“产气中/待机中”巨字；来自老人使用时先确认机器现在在做什么。
2. B「一步一屏」：每屏仅一类任务，先选产气/雾化/暂停，再执行。主角是单个超大主按钮；降低同屏选择负担，但增加一次切换。
3. C「实体面板」：产气与雾化各一列，七条命令全部常显。主角是清晰分组的控制区；接近实体设备控制台，但信息密度较高。
4. D「时间轮盘」：先选择时长，再确认开始。时长并非本次 SRS 七条命令的必填参数，暂不采用。
5. E「极简一键」：只有开始/停止主按钮，其余功能隐藏。对雾化和暂停发现性较差，暂不采用。
6. F「深色夜间」：适合暗室，老人白天看对比和反光风险需另行评估，暂不作为默认版。

下面 A/B/C 做成真实尺寸初稿。推荐 A：状态始终可见，高频操作直达，同时不像 C 那样把七个按钮都压在一屏。

参考输入：现有虚拟人原型的业务状态与项目需求说明书；不沿用人物布局。无外部作品、Logo 或未验证数据被冒充为参考。
