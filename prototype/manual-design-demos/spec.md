# 纯手动操作界面 · 三方向共同约束

- 目标设备：1920×1200 横屏工业 Pad，当前应用可见区约 1920×1080（960×540 CSS 像素）。
- 目标用户：老年人；不依赖语音、人脸、虚拟人或动画完成任何操作。
- 共用内容：产气、雾化、暂停/恢复、睡眠七条标准命令，以及状态、剩余时间、故障提示。
- 关键安全规则：停止产气和睡眠二次确认；未产气不能开始雾化；故障时阻断命令。
- 视觉底线：主要文字 ≥24 CSS px，辅助文字 ≥18 CSS px；操作按钮高 ≥72 CSS px；状态同时用文字和颜色表示。
- 三版都是纯前端演示，不连接真实设备、MCU、麦克风或摄像头；时间与结果为模拟。
- 品牌仅用项目已有“潓美医疗”文字名与蓝青色系；尚无可核实的正式 Logo。
